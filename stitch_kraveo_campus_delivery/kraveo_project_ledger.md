# Kraveo Project Ledger & Documentation

## Project Vision
Kraveo is a specialized food delivery ecosystem designed specifically for the VIT Bhopal campus. It bridges the gap between local dhabas/vendors near the highway and students residing in hostels, addressing non-tech literacy in vendors and specific campus logistics (hostel gates).

## System Architecture
### 1. Customer App (iOS & Android)
- **Target:** VIT Bhopal Students.
- **Key Features:** Menu browsing, hostel-specific drop-off selection, UPI integration, real-time GPS tracking.

### 2. Vendor App (Android)
- **Target:** Local dhaba owners.
- **Key Features:** High-volume audio alerts, ultra-simple UI (Big buttons, color coding), item availability toggles.

### 3. Delivery Partner App (Android/iOS)
- **Target:** Student riders.
- **Key Features:** Order dispatching, navigation to campus gates, one-tap status updates.

### 4. Admin Web Dashboard
- **Target:** Kraveo Founders.
- **Key Features:** Live order monitoring, menu management, driver payouts, manual overrides.

## Tech Stack
- **Frontend:** Flutter (Mobile), React + Tailwind CSS (Web).
- **Backend:** Node.js Express or Firebase/Supabase.
- **Database:** PostgreSQL/Firestore.
- **APIs:** Google Maps (Location), Razorpay (Payments), Firebase Cloud Messaging (Alerts).

## Development Roadmap
- **Phase 1:** UI/UX & Design System (Current)
- **Phase 2:** Backend API & Database Schema
- **Phase 3:** MVP Development (Customer & Vendor core loops)
- **Phase 4:** Real-time Tracking & Logistics
- **Phase 5:** Testing & Campus Rollout
